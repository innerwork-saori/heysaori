what it is

長內容變短影音，整條流程交給 Claude

從聽打逐字稿、挑出精華片段、剪成影片，到寫好貼文文案，
Reels Studio 把這些步驟串在一起，你只要確認和發布。

適合誰

經營 Podcast、訪談節目、講座、直播或個人品牌，想把長內容變成短影音、卻沒時間自己剪的創作者。

桌面上的 Reels Studio 控制台

安裝後會多一個控制台，用點選就能：

  • 設定頻道的配色、字型、版面風格和結尾卡
  • 從五種版面風格中挑一種，再逐項微調字幕、標題卡、背景、線條和動畫
  • 挑選要剪的片段、播放成品、一鍵複製文案

每個頻道可以有自己的風格，經營多個帳號也能各自保持一致的視覺。

how it works

從素材到發文，五個步驟

  1. 聽打在你自己的電腦上做語音辨識，產出逐字稿
  2. 挑精華Claude 從逐字稿裡找出適合做成短影音的片段，你在控制台確認要哪幾段
  3. 剪片剪成 9:16 直式影片，依頻道風格加上字幕、標題卡、插圖和結尾卡
  4. 寫文案寫好貼文文案，整理成發文包
  5. 檢查發布在控制台播放成品、複製文案，自己看過一遍再發

語音辨識在本機執行；逐字稿、文案和剪片時用來檢查畫面的截圖，則會在對話中交給 Claude 處理。

get started

如何開始使用

先填表單索取下載連結，再準備好一台 Windows 電腦，三個步驟就能裝好。

需要什麼

  • Windows 電腦
  • Claude 桌面 App，而且你的方案可以使用 Claude Code
  • 網路連線（安裝時會下載 Python 和套件）
  • C 槽至少空出 3 GB：Python 和套件約 0.4 GB、語音辨識模型約 1.6 GB；之後每支影片約 50–80 MB

安裝步驟

  1. 填寫申請表單，Saori 會把 ReelsStudio.zip 的下載連結提供給你
  2. 用收到的連結下載 ReelsStudio.zip，按右鍵 →「解壓縮全部」
  3. 打開資料夾，先看「① 先看我」，再雙擊「② 雙擊安裝」，照畫面回答
  4. 把 Claude 桌面 App 完全關掉再打開

「① 先看我」是一份可以打勾的檢查表，從安裝、建立頻道設定，一路帶你做完第一支影片。

使用前要知道

  • AI 產生的逐字稿、字幕和文案可能有錯，發布前請完整看過
  • 素材的使用權、來賓或入鏡者的同意由你自行負責
  • 工具本身採 CC BY-NC 4.0，不能拿來賣或收費散布；但用它做出來的影片可以商業使用（業配、店家宣傳、幫客戶做影片都可以）
