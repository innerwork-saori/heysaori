## 操作步驟

說明：藉由職業工作想像，尋找熱情本質，並非職涯規劃方向

### Step 1：挑選出有意願想要嘗試的工作（不考慮能力是否符合）
卡片上標示職稱以及興趣代碼，右上角 (i) 小 icon 點開有職業詳細說明，參考 whatsmytalent.html 的 UI

### Step 2：有意願的工作中分類
分類
1. 純粹喜歡
    如果純粹喜歡未達 10 項，請回第一步重新挑選
2. 他人期望
3. 僅是有能力做
### Step 3：填寫原因
針對 1. 純粹喜歡的工作，逐一填寫喜歡的原因、享受的理由、成就感描述
### Step 4：針對 2. 他人期望 & 3. 僅是有能力做 的工作探索有無洞察
提供輸入欄位讓 User 輸入
### Step 5：工具自動將純粹喜歡的工作分六大類統計，排序六大類呈現
### Step 6：提供一些反思的問題讓 User 可以反思


## UI 設計
參考 whatsmytalent.html 以及 self-discovery-tools.html 的風格

## 功能流程
1. if 有 client storage then load client 端資料
2. if else user 有過去資料 then 匯入 json 資料
3. else 開始填寫新的資料
4. 操作 Step 1、2、3、4、5、6
5. 操作完畢，檢視完整報告頁
6. 選擇資料保存方式
7. if 匯出 json then user 下載 json 檔案
