職涯探索工具
by Saori · career exploration

認識自己，從這裡開始

三個互相呼應的職涯探索工具
幫你看清自己真正在意什麼、擁有什麼
是職涯轉換前最值得做的一件事

why these tools exist

很多人卡關，不是因為能力不夠
而是因為不清楚自己要什麼、有什麼

在職涯諮詢的工作中，我發現一個規律：
大多數人在探索方向之前，需要先做三件事：
釐清價值觀、盤點自己的職能，以及找到真正的熱情所在。

這三個工具，就是為了這個目的而設計的。
它們不會告訴你答案，但會幫你看見自己。

01
self-awareness · values
價值觀探索
Life & Work Values Reflection
人生 × 工作 雙模式
你真正在意的是自由、穩定、成就感、還是關係？
透過系統化的排序與反思流程，找出驅動你的核心價值觀，並評估現況與理想之間的落差。
  • 人生價值觀 × 工作價值觀雙模式探索
  • 重要 / 次要分類 → 篩選排序 → 原因說明
  • 滿意度評分，直視現況落差
  • 結果可匯出儲存，方便諮詢使用

02
self-awareness · strengths
職能盤點
Talent & Skills Inventory
能力 × 職場應用
你以為自己沒什麼特別的，但其實你累積了很多。
這個工具幫你系統性地盤點職能與優勢，找到還沒被充分使用的潛力，以及值得繼續深耕的方向。
  • 全面盤點各類型職能與軟實力
  • 標記「擁有」與「想發展」，方向更清晰
  • 深入了解每項能力的職場應用
  • 支援職缺比對模式，對應求職需求

03
self-awareness · passion
熱情探索
Passion & Interest Discovery
Holland Code 職業興趣框架
知道自己擅長什麼還不夠——你還需要知道什麼事讓你真正「燃起來」。
這個工具以 Holland Code 為核心框架，幫你系統性地探索職業興趣類型，找出與你天生氣質最相符的工作環境與方向。
  • 依據 Holland Code 六大類型進行興趣探索
  • 找出熱情與職能的交集地帶
  • 對應適合的職業方向與工作環境
  • 結合價值觀與職能結果，形成完整自我圖像
