OPENROUTER 使用小抄

三步取得 API Key

  1. 01
    建立帳戶前往 OpenRouter 註冊或登入。
  2. 02
    新增金鑰打開帳戶設定中的 Keys 頁面，建立一組 API Key。
  3. 03
    貼回這裡複製新金鑰，回到產生器貼入 API Key 欄位。

請妥善保管金鑰。模型供應與免費額度依 OpenRouter 當下方案為準。
