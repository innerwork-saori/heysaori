設定 OpenRouter API Key

你的 Key 與隱私，我們這樣處理

  • 不花錢：建立 Key 時把費用上限（Key limit）填 0，帳戶也不用儲值。免費模型照常可用，任何會收費的請求都扣不到錢。
  • 不上傳到本站：Key 只放在你這個瀏覽器分頁裡，不會存進你的電腦，也不會傳到本網站。關掉或重新整理分頁，Key 就清掉了。
  • 只交給 OpenRouter：按下產生時，瀏覽器會直接把 Key 和你輸入的文字送到 OpenRouter 產生結果，中間不經過本站的伺服器。
  • 不蒐集個資：本頁不用登入，不會記下你的姓名、Email、Key 或輸入內容；只用 Google Analytics 統計匿名的瀏覽人次。

小提醒：公用電腦上請別輸入 Key。萬一擔心外流，到 OpenRouter 刪掉這組 Key、再建一組就好。

OPENROUTER 使用小抄

三步取得 API Key

  1. 01
    建立帳戶前往 OpenRouter 註冊或登入。
  2. 02
    新增金鑰，費用上限填 0打開帳戶設定中的 Keys 頁面，按 Create Key。在 Key limit（費用上限）欄位填 0，這組 Key 就不會花到錢。
  3. 03
    貼回這裡複製新金鑰，回到產生器貼入 API Key 欄位。

本頁使用的是免費模型（價格 $0），不需要綁信用卡或儲值。費用上限設 0、帳戶不儲值，就算 Key 不小心外流也扣不到錢。免費額度與模型供應依 OpenRouter 當下方案為準。
