API Key 安全提醒

Key 只留在目前分頁的瀏覽器記憶體，不會寫入本網站的儲存空間或伺服器。產生時，瀏覽器會直接把 Key 傳給 OpenRouter；在瀏覽器輸入的 Key 仍可能被這台裝置上的使用者透過開發者工具查看。

請只輸入自己的 Key，避免在公用或共用裝置使用。關閉或重新整理分頁會清除欄位；若懷疑 Key 外洩，請到 OpenRouter 撤銷並重新建立。

OPENROUTER 使用小抄

三步取得 API Key

  1. 01
    建立帳戶前往 OpenRouter 註冊或登入。
  2. 02
    新增金鑰打開帳戶設定中的 Keys 頁面，建立一組 API Key。
  3. 03
    貼回這裡複製新金鑰，回到產生器貼入 API Key 欄位。

請妥善保管金鑰。模型供應與免費額度依 OpenRouter 當下方案為準。
