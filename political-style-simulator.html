開始轉換

設定 OpenRouter API Key

Key 只在這個分頁記憶體中使用，重新整理或關閉頁面就會清除。瀏覽器直接呼叫 API 時，金鑰仍可能被使用者透過開發者工具查看；請勿在公用或不信任的裝置使用。正式公開給他人使用時，建議改由自有後端代呼叫。

「萬安體」依公共發言中的程序化、穩健語氣特徵進行戲仿，不代表真實政策、事實或任何人物原話。「伯洋體」依你提供的公開論述特徵進行戲仿，不代表沈伯洋本人發言；內容不會虛構研究、數據或引言。

OPENROUTER 使用小抄

三步取得 API Key

  1. 01
    建立帳戶前往 OpenRouter 註冊或登入。
  2. 02
    新增金鑰打開帳戶設定中的 Keys 頁面，建立一組 API Key。
  3. 03
    貼回這裡複製新金鑰，回到產生器貼入 API Key 欄位。

請妥善保管金鑰。模型供應與免費額度依 OpenRouter 當下方案為準。
